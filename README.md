# Smart Facade — сайт и админка

Многоязычный сайт (RU / UZ / EN) на Next.js со встроенной админкой.
Всё содержимое сайта лежит в папке `content/` в виде обычных JSON-файлов,
картинки — в `public/`.

## Запуск на своём компьютере

```bash
npm install
npm run dev
```

- сайт: http://localhost:3000
- админка: http://localhost:3000/admin

Пароль админки хранится в `content/admin.json` (этот файл намеренно не попадает в
репозиторий). По умолчанию — `smartfacade2026`, поменяйте его в разделе «Обзор».

## Что где лежит

| Папка | Что внутри |
| --- | --- |
| `content/` | тексты, проекты, партнёры, контакты, настройки SEO, заявки |
| `public/img`, `public/icons` | картинки и иконки из вёрстки |
| `public/uploads` | всё, что загружено через админку |
| `src/app` | страницы сайта и админки |
| `src/components` | блоки сайта |

## Переменные окружения

Смотрите `.env.example`. На сервере нужны:

- `ADMIN_PASSWORD` — пароль админки. **Без него админка на боевом сайте закрыта.**
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — уведомления о заявках.

## Про хостинг: важно

Админка сохраняет правки в файлы проекта. Это работает на обычном сервере и на
вашем компьютере, но **не работает на Vercel** — там файловая система только для
чтения.

Что это значит на Vercel:

- сайт открывается и работает полностью;
- админка открывается, но кнопка «Сохранить» вернёт ошибку (об этом честно
  предупреждает жёлтая плашка сверху);
- заявки не сохраняются в файл — поэтому **обязательно** заполните
  `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, иначе заявка не дойдёт и посетитель
  увидит ошибку;
- счётчик посещений на «Обзоре» не считает (для статистики подключите
  Google Analytics или Яндекс.Метрику в разделе SEO).

Рабочий порядок при таком раскладе: правите содержимое в админке **на своём
компьютере**, отправляете изменения на GitHub — Vercel сам пересобирает сайт.

Чтобы админка заработала прямо на сайте, содержимое и загрузки нужно перенести в
базу и облачное хранилище, либо выбрать хостинг с обычным диском
(Railway, Render, VPS).

## Публикация на Vercel

1. Загрузите проект в репозиторий на GitHub.
2. На vercel.com → **Add New → Project** → выберите этот репозиторий.
3. Framework Preset определится сам (Next.js), менять ничего не нужно.
4. В **Environment Variables** добавьте `ADMIN_PASSWORD`, а также
   `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
5. **Deploy**.
6. После первой публикации откройте админку у себя на компьютере →
   раздел **SEO** → впишите адрес сайта в поле «Адрес сайта», сохраните и
   отправьте изменения на GitHub. Без этого не будут работать карта сайта и
   правильные ссылки в поиске.
